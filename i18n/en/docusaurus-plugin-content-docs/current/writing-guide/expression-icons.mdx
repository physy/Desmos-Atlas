## Hidden state

Set `hidden: true` to fade the icon while preserving the icon shape.

<DesmosExpression
  ariaLabel="Hidden expression icons"
  expressions={[
    { expression: "y=\\sin x", type: "parametricSolid", color: "red", hidden: true },
    { expression: "y\\leq x^2", type: "inequality", color: "blue", hidden: true },

## Use the component in an article

```jsx
import DesmosExpression from "@site/src/components/DesmosExpression";

<DesmosExpression
  expressions={[
    { expression: "y=\\sin x", type: "parametricSolid", color: "red" },
    { expression: "y\\leq x^2", type: "inequality", color: "blue" },
    { expression: "(1,2)", type: "point", color: "green" },
    { expression: "a\\to a+1", type: "action" },
    { expression: "Explanatory text", type: "note" },
  ]}
/>;
```

When omitted, `type` defaults to `parametricSolid` and `color` defaults to `blue`.
