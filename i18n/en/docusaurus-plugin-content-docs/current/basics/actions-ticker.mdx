# Actions and Tickers

Actions and tickers greatly expand what a Desmos graph can do by updating variables and running operations repeatedly.

## Actions

### Action basics

Define $a$, then enter `a->a+1`. Desmos converts the arrow and recognizes the expression as an action. Press its action button to increase $a$ by one.

<DesmosExpression expressions={[
  'a=1', {type: 'action', expression: 'a\\to a+1', color: 'blue'},
]} />

<ArticleImage className="desmos-article-image" src="/img/basic/actions/action.gif" alt="Running an action to increase variable a" loading="lazy" />

### Multiple updates

Comma-separated updates run simultaneously. Their right-hand sides use values from before the action runs.

<DesmosExpression expressions={[
  'a=2', 'b=1', {type: 'action', expression: 'a\\to a+1,b\\to a', color: 'blue'},
]} />

After one run, $a=3,b=2$. One action cannot contain multiple update rules for the same variable.

### Assigning actions to variables

<DesmosExpression expressions={[
  'a=2', 'b=1',
  {type: 'action', expression: 'A=a\\to a+1', color: 'blue'},
  {type: 'action', expression: 'B=b\\to b+1', color: 'green'},
  {type: 'action', expression: 'C=A,B', color: 'purple'},
]} />

Running $C$ runs $A$ and $B$ together. The same no-duplicate-update rule still applies.

### Running an action by clicking a graph

Points, curves, and labels can be made clickable and assigned an action.

<ArticleImage className="desmos-article-image" src="/img/basic/en/desmosuse/6.png" alt="Making an expression clickable and assigning an action" loading="lazy" />

<DesmosEmbed id="yselxxvgos" title="Running actions by clicking the graph" height={540} options={{expressions: true}} />

Click the “increase/decrease by 1” labels to change $a$.

## Tickers

A ticker runs an action at a regular interval. Select “ticker” from the Add menu. If it is not listed, create an action first.

<ArticleImage className="desmos-article-image" src="/img/basic/en/actions/1.png" alt="Selecting ticker from the Add menu" loading="lazy" />

Enter an action in the Run field and an interval in milliseconds on the right, then use the metronome button to start it.

<ArticleImage className="desmos-article-image" src="/img/basic/actions/ticker-settings.png" alt="Setting a ticker action and interval" loading="lazy" />

## Measuring elapsed time with `dt`

Heavy calculations may prevent a ticker from keeping its requested interval. This example runs $t\to t+1$ every millisecond, but its displayed time drifts from real time.

<DesmosEmbed id="oskelj8c6z" title="A ticker that cannot keep up" height={540} options={{expressions: true}} />

The special variable $\mathrm{dt}$ contains the elapsed milliseconds since the previous tick. Updating $t\to t+\mathrm{dt}$ reduces dependence on device performance.

<ArticleImage className="desmos-article-image" src="/img/basic/en/actions/2.png" alt="Using dt in a ticker" loading="lazy" />

<DesmosEmbed id="bi4thnfywv" title="A ticker corrected with dt" height={540} options={{expressions: true}} />

## Lists and `index`

When clicking one of several list-generated objects, the special variable $\mathrm{index}$ identifies which item was clicked.
