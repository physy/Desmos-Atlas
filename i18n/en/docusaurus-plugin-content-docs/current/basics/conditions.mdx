# Restrictions and Conditionals

Desmos uses braces `{}` for domain and range restrictions as well as simple conditional expressions.

## Restrictions

Append a condition in braces to an expression. Restrictions also work with implicit equations and inequalities.

<DesmosExpression
  expressions={[
    { expression: "y=x\\{x<0\\}", type: "parametricSolid", color: "red" },
    { expression: "x=1\\{y\\geq0\\}", type: "parametricSolid", color: "blue" },
    { expression: "x>0\\{x^2+y^2>4\\}", type: "inequality", color: "green" },
  ]}
/>

## Multiple conditions

Comma-separated conditions inside one pair of braces behave like “or.” Separate pairs of braces behave like “and.”

<DesmosExpression
  expressions={[
    { expression: "x^2+y^2=1\\{x>0,y>0\\}", type: "parametricSolid", color: "black" },
    { expression: "x^2+y^2=4\\{x>0\\}\\{y>0\\}", type: "parametricSolid", color: "purple" },
  ]}
/>

## Conditional expressions

Use `{condition 1: value 1, condition 2: value 2, …}` to switch values according to conditions.

<DesmosExpression
  expressions={[
    {
      expression: "y=\\{x<0:x+1,0\\leq x<1:1,1\\leq x:x\\}",
      type: "parametricSolid",
      color: "red",
    },
    { expression: "a=\\cdots", type: "pause" },
    { expression: "(x-1)^2+(y+1)^2=\\{a<0:1,a>0:4\\}", type: "parametricSolid", color: "green" },
  ]}
/>

Complex logical conditions can often be rewritten mathematically—for example, $a<1$ and $b>2$ can be expressed as $\min(-a+1,b-2)>0$—or built with nested braces.

## How braces work

1. Conditions are evaluated from left to right, and the matching value is returned.
2. If the value is omitted, Desmos returns $1$.
3. If no condition matches, the containing expression is not drawn or executed.

Thus `y=x\{x<0\}` draws `y=x·1` only when $x<0$. Similarly, `x^2+y^2=4\{x>0\}\{y>0\}` appears only where both braces evaluate to $1$.
