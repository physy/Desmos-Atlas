# Getting Started with Desmos

The [Desmos Graphing Calculator](https://www.desmos.com/calculator) is a web application for drawing graphs intuitively. A smartphone app is also available.

Let’s start by drawing a few expressions.

## Types of expressions

Desmos can draw explicit and implicit functions, inequalities, and points.

## Adding variables

Characters other than special graph variables such as $x,y,r,\theta$ can store values. Entering an undefined variable displays an “Add Slider” button.

<ArticleImage
  className="desmos-article-image"
  src="/img/desmos-use/slider.png"
  alt="Adding a variable slider in Desmos"
  loading="lazy"
/>

Sliders provide direct control over values. You can set bounds and step sizes or animate the variable with the play button.

:::info[Note]

Variables can normally be referenced from every expression. Use `for` or `with` when you need a local variable. See [`for` and `with`](./for-with).

:::

## Adding notes

Select “note” from the Add menu. On a computer, starting an empty expression with `"` also converts it into a note.

## Reordering and folders

Drag the left side of an expression or note to reorder it. Folders can group several items; drag expressions below a folder to include them. Typing `folder` into an empty expression creates one directly.

## Saving and sharing

Create a Desmos account to save graphs and manage them from the left menu. On a computer or tablet, use the Share button in the top right to generate a URL that opens the same graph for anyone.
