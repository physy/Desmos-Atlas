# Control graphs with JavaScript

`DesmosCalculator` handles loading the API, initialization, and cleanup. Expressions and controls specific to an article stay in MDX.

<DesmosCalculator
  height={520}
  expressions={waveExpressions}
  bounds={{left: -8, right: 8, bottom: -5, top: 5}}
>
  <DesmosControls label="Choose a graph">
    <DesmosButton onPress={(calculator) => {
      calculator.removeExpression({id: 'shape'});
      calculator.setExpression({id: 'wave', latex: 'y=a\\sin(bx)', color: '#388c46'});
    }}>
      Sine wave
    </DesmosButton>
    <DesmosButton onPress={(calculator) => {
      calculator.removeExpression({id: 'wave'});
      calculator.setExpression({id: 'shape', latex: 'x^2+y^2=9', color: '#2d70b3'});
    }}>
      Circle
    </DesmosButton>
    <DesmosButton onPress={(calculator) => {
      calculator.removeExpression({id: 'wave'});
      calculator.setExpression({
        id: 'shape',
        latex: '(t\\cos(t),t\\sin(t))',
        parametricDomain: {min: '0', max: '6\\pi'},
        color: '#6042a6',
      });
    }}>
      Spiral
    </DesmosButton>
  </DesmosControls>
</DesmosCalculator>

## Choose the initial data

Pass exactly one of an `expressions` array, a saved `state`, or the `hash` at the end of a Desmos URL.

```mdx
<DesmosCalculator expressions={expressions} />
<DesmosCalculator state={savedState} />
<DesmosCalculator hash="xfsfswckqy" showCaption />
```

With `hash`, the component fetches the saved state from Desmos and loads it through `setState()`. Add `showCaption` to link back to the original graph.

## 2D, 3D, and Geometry

Select the Desmos tool with `kind`. It defaults to `2d`.

```mdx
<DesmosCalculator kind="2d" expressions={expressions} />
<DesmosCalculator kind="3d" state={threeDimensionalState} />
<DesmosCalculator kind="geometry" hash="saved-geometry-hash" />
```

For more advanced custom components, use `onReady` or `useDesmosCalculator()` to access the Calculator instance.

:::caution[Using the API in production]

This site currently uses the development demo API key. Before publishing, obtain a production API key with every required feature—including 3D and Geometry—enabled.

:::
