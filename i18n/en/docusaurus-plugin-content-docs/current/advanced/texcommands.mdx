# TeX Command Reference

This page lists $\TeX$ ($\LaTeX$) commands recognized in Desmos labels and expressions. Most standard commands work, although some are not fully supported inside expressions.

To use TeX in a label, enclose the TeX section in backticks. See [Points, Labels, and Vectors](../basics/points-vectors.mdx) for details.

## Special Commands

These appear to be intended for internal processing and are not recommended for ordinary graphs or articles.

| Output | Command                               | Notes                                                                                                                                                        |
| ------ | ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |

|        | `\token{number}`                      |                                                                                                                                                              |
| $a$    | `\editable{a} \MathQuillMathField{a}` |                                                                                                                                                              |
|        | `\embed{}`                            |                                                                                                                                                              |
