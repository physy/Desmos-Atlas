# TeXコマンド一覧

Desmosのラベルや数式で使える $\TeX$（$\LaTeX$）コマンドの一覧です。標準的なコマンドの多くを利用できますが、一部は数式中で正しく認識されない場合があります。

ラベルでTeXを使う場合は、TeX部分をバッククォートで囲みます。詳しくは[点・ラベル・ベクトル](../basics/points-vectors.mdx)を参照してください。

## 特殊なコマンド

内部処理向けと思われるため、通常の記事やグラフでの使用は推奨しません。

| 出力 | コマンド                              | 備考                                                                                                                        |
| ---- | ------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
|      | `\tildeNbsp`                          | 改行させない半角スペースである &nbsp; が挿入されるよう。\sim として認識される？                                             |
|      | `\class{クラス名}{a}`                 | 任意のクラス名の span タグで囲める<br />入れ子にもできるので上手くクラス名を指定すれば css を当てさせることもできなくはない |
|      | `\token{特定の数字}`                  | Desmos の他のツールで使われる                                                                                               |
| $a$  | `\editable{a} \MathQuillMathField{a}` | 不明                                                                                                                        |
|      | `\embed{}`                            | 不明                                                                                                                        |
