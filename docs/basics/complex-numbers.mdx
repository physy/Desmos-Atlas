# 複素数

Desmosの複素数モードを使うと、複素数平面を直感的に描画できます。

## 複素数モードを有効にする

設定画面にある「複素数モード」のスイッチをオンにします。

<img className="desmos-article-image" src="/img/basic/complex/settings.png" alt="Desmosの複素数モード設定" loading="lazy" />

## 複素数平面

複素数を入力すると、自動的に複素数平面上の点として描画されます。

<DesmosExpression expressions={[
  {type: 'point', expression: 'i', color: 'red'},
  {type: 'point', expression: '1+2i', color: 'blue'},
]} />

## 複素数の演算

<DesmosExpression expressions={[
  '(1+i)+(2-2i)=3-i',
  '(1+i)(2-2i)=4',
  '\\mathrm{real}(2+4i)=2',
  '\\mathrm{imag}(2+4i)=4',
  '\\mathrm{conj}(2+4i)=2-4i',
  '\\mathrm{arg}(1+i)=\\frac{\\pi}{4}',
  '|3+4i|=5',
  'e^{i\\pi}=-1',

実部、虚部、共役、偏角、絶対値に加え、オイラーの公式も扱えます。
