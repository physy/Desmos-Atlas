# 範囲指定と条件分岐

Desmosでは波括弧 `{}` を使って、定義域・値域の制限や条件分岐を行えます。

## 範囲・条件を設定する

式の最後へ波括弧で条件を書きます。陽関数だけでなく、陰関数や不等式にも利用できます。

<DesmosExpression
  expressions={[
    { expression: "y=x\\{x<0\\}", type: "parametricSolid", color: "red" },
    { expression: "x=1\\{y\\geq0\\}", type: "parametricSolid", color: "blue" },
    { expression: "x>0\\{x^2+y^2>4\\}", type: "inequality", color: "green" },
  ]}
/>

## 複数の条件

波括弧内をカンマで区切ると「いずれか」、波括弧を並べると「すべて」の条件として評価されます。

<DesmosExpression
  expressions={[
    { expression: "x^2+y^2=1\\{x>0,y>0\\}", type: "parametricSolid", color: "black" },
    { expression: "x^2+y^2=4\\{x>0\\}\\{y>0\\}", type: "parametricSolid", color: "purple" },
  ]}
/>

## 条件分岐

`{条件1: 式1, 条件2: 式2, …}` の形で、条件ごとに値や式を切り替えられます。

<DesmosExpression
  expressions={[
    {
      expression: "y=\\{x<0:x+1,0\\leq x<1:1,1\\leq x:x\\}",
      type: "parametricSolid",
      color: "red",
    },
    { expression: "a=\\cdots", type: "pause" },
    { expression: "(x-1)^2+(y+1)^2=\\{a<0:1,a>0:4\\}", type: "parametricSolid", color: "green" },
  ]}
/>

<DesmosEmbed
  id="tykcpjy4v0"
  title="条件分岐の例"

  options={{ expressions: true, settingsMenu: false, trace: true }}
/>

「かつ」は $\min(-a+1,b-2)>0$ のように数式へ置き換えたり、波括弧を入れ子にしたりして表現できます。

## 波括弧の仕組み

`{条件1: 式1, 条件2: 式2, …}` は次の順序で動作します。

1. 左から条件を評価し、成立した条件に対応する式を返す
2. 対応する式を省略した場合は $1$ を返す
3. どの条件も成立しなければ、波括弧を含む式全体を描画・実行しない

したがって `y=x\{x<0\}` は、$x<0$ のときだけ `y=x·1` を描画します。また `x^2+y^2=4\{x>0\}\{y>0\}` は両方の波括弧が $1$ になる領域だけを描画します。
