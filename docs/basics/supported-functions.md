# 使用できる関数一覧

## グラフ計算機

### 三角関数

| 関数 | 入力例 | 意味 |
| --- | --- | --- |
| $\sin$ | `sin(x)` | サイン |
| $\cos$ | `cos(x)` | コサイン |
| $\tan$ | `tan(x)` | タンジェント |
| $\csc$ | `csc(x)` | コセカント $(1/\sin x)$ |
| $\sec$ | `sec(x)` | セカント $(1/\cos x)$ |
| $\cot$ | `cot(x)` | コタンジェント $(1/\tan x)$ |

### 逆三角関数

| 関数 | 入力例 | 意味 |
| --- | --- | --- |
| $\arcsin$ | `arcsin(x)` | アークサイン |
| $\arccos$ | `arccos(x)` | アークコサイン |
| $\arctan$ | `arctan(x)` | アークタンジェント |
| $\operatorname{arccsc}$ | `arccsc(x)` | アークコセカント |
| $\operatorname{arcsec}$ | `arcsec(x)` | アークセカント |
| $\operatorname{arccot}$ | `arccot(x)` | アークコタンジェント |

### 統計

| 関数 | 入力例 | 意味 |
| --- | --- | --- |
| `mean` | `mean([1,3,4])` | 平均値 |
| `median` | `median([1,3,4])` | 中央値 |
| `min` / `max` | `min([1,3,4])` | 最小値／最大値 |
| `quartile` | `quartile([1,3,4],2)` | 四分位数 |
| `quantile` | `quantile([1,3,4],0.2)` | 分位数 |
| `stdev` / `stdevp` | `stdev([1,3,4])` | 標本／母標準偏差 |
| `var` / `varp` | `var([1,3,4])` | 標本／母分散 |
| `mad` | `mad([1,3,4])` | 平均絶対偏差 |
| `cov` / `covp` | `cov([2,4,5],[1,3,2])` | 標本／母共分散 |
| `corr` | `corr([2,4,5],[1,3,2])` | ピアソンの積率相関係数 |
| `spearman` | `spearman([2,4,5],[1,3,2])` | スピアマンの順位相関係数 |
| `stats` | `stats([1,3,3,4,5])` | 五数要約 |
| `count` | `count([1,3,3,4,5])` | 要素数 |
| `total` | `total([1,3,4])` | 合計値 |

### リスト操作

| 関数 | 入力例 | 意味 |
| --- | --- | --- |
| `join` | `join([1,2],[3,4])` | リストを結合 |
| `sort` | `sort([1,5,4])` | リストを並べ替える |
| `shuffle` | `shuffle([1,5,4])` | リストをシャッフル |
| `unique` | `unique([1,5,5,6])` | 重複を取り除く |
| `for` | `(a,0) for 1<a<3` | パラメータ表示やリスト処理 |

### 可視化

| 関数 | 入力例 | 意味 |
| --- | --- | --- |
| `histogram` | `histogram([1,5,5,10])` | ヒストグラム。第2引数に幅を指定可能 |
| `dotplot` | `dotplot([1,5,5,10])` | ドットプロット。第2引数に幅を指定可能 |
| `boxplot` | `boxplot([1,5,5,10])` | 箱ひげ図 |

### 確率分布

| 関数 | 入力例 | 意味 |
| --- | --- | --- |
| `normaldist` | `normaldist(0,1)` | 平均値と標準偏差による正規分布 |
| `tdist` | `tdist(10)` | 自由度によるt分布 |
| `chisqdist` | `chisqdist(5)` | 自由度によるカイ二乗分布 |
| `poissondist` | `poissondist(5.5)` | 平均値によるポアソン分布 |
| `binomialdist` | `binomialdist(10,0.3)` | 試行回数と成功確率による二項分布 |
| `uniformdist` | `uniformdist(0,1)` | 区間による一様分布 |
| `pdf` | `pdf(D,x)` | 確率密度関数 |
| `cdf` | `cdf(D,x)` | 累積分布関数 |
| `inversecdf` | `inversecdf(D,x)` | 分位関数（逆累積分布関数） |
| `random` | `random()` | $0$ 以上 $1$ 未満の乱数。リストではランダムな要素 |

### 統計検定

| 関数 | 入力例 | 意味 |
| --- | --- | --- |
| `ttest` | `ttest([20,31,51],40)` | 標本と値へのt検定 |
| `tscore` | `tscore([20,31,51],40)` | 標本と値に対するt値 |
| `ittest` | `ittest([10,13],[21,23])` | 2標本へのt検定 |

| $\log_a$ | `log_a(x)` | 任意の底の対数 |
| $\frac{d}{dx}$ | `d/dx` | $x$ で微分 |
| $f'(x)$ | `f'(x)` | 関数を微分 |
| $\int$ | `int` | 積分 |
| $\sum$ | `sum` | 数列の総和 |
| $\prod$ | `prod` | 数列の総積 |

## 3D計算機

2Dの関数に加えて、以下の関数や座標を利用できます。

### 球座標・円筒座標

| 記号 | 入力例 | 意味 |
| --- | --- | --- |
| $\rho$ | `rho` | 球座標で原点からの距離 |
| $\theta$ | `theta` | 方位角 |
| $\phi$ | `phi` | 天頂角 |
| $r$ | `r` | 円筒座標で $z$ 軸からの距離 |

### 3D幾何学

| 関数・プロパティ | 入力例 | 意味 |
| --- | --- | --- |
| `segment` | `segment((0,0,0),(2,2,2))` | 線分 |
| `triangle` | `triangle((0,0,0),(2,2,2),(1,3,2))` | 三角形 |
| `sphere` | `sphere((0,0,0),1)` | 中心と半径を指定した球 |
| `vector` | `vector((0,0,0),(1,1,1))` | 始点と終点を指定したベクトル |
| `length` | `length(v_1)` | ベクトルまたは線分の長さ |
| `.start` | `v_1.start` | ベクトルの始点 |
| `.end` | `v_1.end` | ベクトルの終点 |
