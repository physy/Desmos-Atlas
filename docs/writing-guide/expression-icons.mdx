# 式アイコン一覧

`DesmosExpression` で指定できる18種類のアイコンを表示します。

<DesmosExpression
  ariaLabel="DesmosExpressionの全アイコン"
  expressions={[
    { expression: "\\mathrm{parametricSolid}", type: "parametricSolid", color: "red" },
    { expression: "\\mathrm{parametricDashed}", type: "parametricDashed", color: "red" },
    { expression: "\\mathrm{parametricDotted}", type: "parametricDotted", color: "red" },
    { expression: "\\mathrm{inequality}", type: "inequality", color: "blue" },
    { expression: "\\mathrm{point}", type: "point", color: "green" },
    { expression: "\\mathrm{points}", type: "points", color: "purple" },
    { expression: "\\mathrm{move}", type: "move", color: "purple" },
    { expression: "\\mathrm{moveVertical}", type: "moveVertical", color: "purple" },
    { expression: "\\mathrm{moveHorizontal}", type: "moveHorizontal", color: "purple" },
    { expression: "\\mathrm{polygonSolid}", type: "polygonSolid", color: "blue" },
    { expression: "\\mathrm{polygonDashed}", type: "polygonDashed", color: "blue" },
    { expression: "\\mathrm{polygonDotted}", type: "polygonDotted", color: "blue" },
    { expression: "\\mathrm{action}", type: "action" },
    { expression: "\\mathrm{play}", type: "play" },
    { expression: "\\mathrm{pause}", type: "pause" },
    { expression: "\\mathrm{error}", type: "error" },
    { expression: "note", type: "note" },
    { expression: "folder", type: "folder" },
  ]}
/>

## 非表示状態

`hidden: true` を指定すると、形状を維持したままアイコンが薄く表示されます。

<DesmosExpression
  ariaLabel="非表示状態のアイコン"
  expressions={[
    { expression: "y=\\sin x", type: "parametricSolid", color: "red", hidden: true },
    { expression: "y\\leq x^2", type: "inequality", color: "blue", hidden: true },
    { expression: "(1,2)", type: "point", color: "green", hidden: true },
    { expression: "a\\to a+1", type: "action", hidden: true },
    { expression: "非表示のメモ", type: "note", hidden: true },
  ]}
/>

## 記事で使う

```jsx
import DesmosExpression from "@site/src/components/DesmosExpression";

<DesmosExpression
  expressions={[
    { expression: "y=\\sin x", type: "parametricSolid", color: "red" },
    { expression: "y\\leq x^2", type: "inequality", color: "blue" },
    { expression: "(1,2)", type: "point", color: "green" },
    { expression: "a\\to a+1", type: "action" },
    { expression: "説明文", type: "note" },
  ]}
/>;
```

`type` を省略した場合はアイコンは表示されません。
